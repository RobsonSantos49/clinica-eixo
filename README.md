# Clínica Eixo · site-modelo

Site-modelo cinematográfico para clínica de ortopedia e fisioterapia. A abertura é um vídeo que avança conforme a rolagem.

**Todos os dados são fictícios:** nome da clínica, profissionais, registros, depoimentos, convênios, endereço, telefone e e-mail.

Ver no ar: https://robsonsantos49.github.io/clinica-eixo/

## Para adaptar a uma clínica real

- `config.js`: WhatsApp, e-mail de destino do formulário e assunto.
- `index.html`: textos. Os blocos fictícios estão marcados com `<!-- EXEMPLO -->`.
- `assets/logo/`: logo e ícones.
- Publicidade médica exige o nome e o CRM do diretor técnico (Resolução CFM 2.336/2023).
- O formulário usa o FormSubmit, que precisa ser ativado no primeiro envio, por um e-mail de confirmação.
